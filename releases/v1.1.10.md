# 뉴스 모니터 v1.1.10

2026-11-04 성능 개선 빌드입니다. 기관 설정에서 입력 지연을 줄이고, 기사 갱신과 통신 작업자가 PC 자원을 불필요하게 점유하는 동작을 개선했습니다.

41. **기관 검색·편집 반응성**: 검색어 입력은 즉시 반영하고 기관 필터와 조건 미리보기는 입력이 150ms 멈추면 갱신합니다. 상세 검색어는 항목마다 전체를 다시 그리지 않고 한 번에 갱신합니다. 같은 기관·분류의 중복 갱신을 생략하고, 창을 닫으면 예약된 갱신도 취소합니다.
42. **통신 작업자 재사용과 회수**: 이미 실행 중인 유휴 작업자를 우선 재사용합니다. 90초 이상 사용하지 않은 작업자는 최대 30초 간격의 점검에서 종료합니다. 처리 중인 요청은 유휴 회수 대상에서 제외하고, 최대 8개 동시 통신·전체 제한시간·타임아웃 후 작업자 교체를 유지합니다.
43. **백그라운드 기사 갱신**: 실행 중 목록 조회·필터링·대표 기사 계산과 본문 비교 준비를 UI 스레드 밖에서 처리합니다. 갱신 요청이 몰리면 마지막 대기 요청으로 합치며, 이전 필터·설정의 결과는 반영하지 않습니다. 읽기 중에는 새 결과를 기존처럼 페이지 전환 또는 `새 결과 보기`에서 적용합니다. 화면 필터와 관계없이 전체 활성 기관의 공유 대상을 유지합니다.
44. **조회·화면 갱신 비용 감소**: 현재 조회에 필요한 태그·본문·요약·본문 비교 결과만 읽고, 검색 규칙은 변경됐을 때 다시 만듭니다. 수집 결과 처리 예산을 12ms 단위로 줄이고 업데이트 상태 화면은 값이 바뀔 때 갱신합니다.

기존 수집 범위, 공유 보류 시간, 중요도·중복 판정 기준, 기관별 대표 기사 규칙은 유지합니다. 본문 유사도 알고리즘과 임계값은 변경하지 않았습니다.

## 적용

1. 뉴스 모니터를 종료하고 기존 EXE와 옆의 `data` 폴더를 백업합니다.
2. 새 `NewsMonitor.exe`를 같은 위치에 넣습니다. `data` 폴더는 그대로 유지합니다.
3. 같은 Windows 계정에서 실행하고 창 제목 또는 `프로그램 / 업데이트`에서 **1.1.10**을 확인합니다.

이번 파일은 로컬에서 제작한 빌드입니다. GitHub 릴리스 게시 및 다른 PC의 자동 업데이트 배포는 별도입니다. 장시간 실제 서버 운영 시 자원 사용량은 기관 수·기사량·네트워크 상태에 따라 달라집니다.
