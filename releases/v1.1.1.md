# v1.1.1 — 뉴스 공유 중복 방지

- 카카오톡 수신자와 텔레그램 방별로 기존 대기·전송 중·성공·결과 불명 이력과 비교합니다.
- 다른 URL의 유사 기사, 기사 묶음의 대표 URL 변경, 추적 매개변수 차이로 인한 재공유를 차단합니다.
- 재시작 후에도 이력을 사용하고, 기존 대기열은 발송 직전에 다시 검사합니다.
- 전송 내역에 `중복 제외`를 표시합니다. 중요도 필터나 일일 건수 제한은 추가하지 않습니다.
- 텔레그램은 기존 최소 4초 간격과 429 재시도를 유지하고 유료 발송을 명시적으로 차단합니다.

텔레그램 공식 FAQ에는 일일 무료 건수 제한이 없고 발송 속도 제한이 안내되어 있습니다.
