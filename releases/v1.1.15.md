# 뉴스 모니터 v1.1.15

자동 업데이트 직후 재시작에서 `Could not load PyInstaller's embedded PKG archive from the executable`가 나오지만, 다시 직접 실행하면 정상 동작하는 사례에 대응해 설치 후 실행 준비 확인을 보강했습니다.

- 이전 Python GUI뿐 아니라 같은 EXE의 부모 부트로더가 종료될 때까지 기다린 뒤 교체합니다.
- 설치기는 복사된 EXE의 전체 SHA-256을 확인하고 잠시 기다린 뒤 다시 읽어 확인합니다. v1.1.14 등 이전 버전의 업데이트 코드로 설치할 때도 이 검사가 적용됩니다.
- 새 업데이트 도우미는 설치된 EXE를 쓰기·삭제 공유 없이 끝까지 읽고, 체크섬이 연속 두 번 일치한 뒤 실행합니다. 일시적인 파일 잠금은 최대 약 20초 동안 재시도합니다.
- 실행 직후 비정상 종료하는 경우 실패를 기록하고 이전 EXE 복원을 시도합니다. 시작 준비 확인이 끝나기 전에는 기존 백업을 유지합니다.
- 설정·기사·봇 정보와 v1.1.14의 전용 Python 런타임 위치는 유지합니다.

## 확인 범위

업데이트 후 재실행이 정상인 사용자 사례와 배포 파일·기존 검증 기록을 확인했습니다. 해당 PC에서 어떤 프로세스가 일시적인 읽기 실패를 일으켰는지는 확인하지 못했습니다. 동일한 PC의 오류를 직접 재현했다고 주장하지 않습니다. 별도의 테스트에서는 EXE 파일을 독점 잠금한 뒤 해제하여, 준비 검사가 기다렸다가 성공하는 것과 내용이 다른 파일을 거부하는 것을 검증합니다.

로컬 전체 테스트 306개를 통과했습니다. 실제 EXE 실행, 자동 설치 후 재시작과 v1.1.14 EXE에서 수정 설치기로 업데이트하는 검사를 통과했습니다. 릴리스 자동 검증에도 실제 부모 부트로더가 있는 EXE 업데이트 검사를 추가했습니다.

## 적용

기존 설치형 앱은 자동 업데이트하거나 설정의 `업데이트 확인`을 누르세요. 수동 설치는 기존 앱을 종료한 뒤 `NewsMonitor-Setup-1.1.15.exe`를 실행합니다. 설치 직후 오류 창이 뜨더라도 이후 직접 실행이 정상이라면 기존 데이터가 삭제된 것은 아닙니다. 계속 실행되지 않는 경우 설치 폴더의 EXE와 업데이트 폴더의 `setup.log`·`update.log`를 확인해야 합니다.
