# News Monitor v1.1.11

- 약관 동의, 설치 경로, 바탕화면 바로가기를 제공하는 사용자별 Windows 설치 프로그램.
- 기존 data 전체를 백업한 뒤 LocalAppData의 NewsMonitor/data로 자동 이전. 기존 데이터 및 백업 보존.
- 검증된 업데이트를 사용자 캐시에 다운로드하고 작업 완료 후 자동 종료·교체·재실행.
- 설정 창을 편집 중이거나 기사 수집·알림 전송 중이면 재시작 대기.

## 설치 및 기존 데이터 유지

`NewsMonitor-Setup-1.1.11.exe`를 내려받아 기존 프로그램을 종료한 뒤 실행하세요.
약관 동의 → 설치 위치 → 기존 `data` 폴더 확인 → 바로가기 선택 순서로 설치합니다.
설치 파일 옆 또는 상위 폴더에서 `data/settings.json`을 찾으며, 다른 위치이면 직접 선택할 수 있습니다.
첫 실행 시 `%LOCALAPPDATA%\NewsMonitor\backups`에 백업한 뒤 `data`로 복사합니다.
기존 원본과 이미 이전한 데이터는 덮어쓰거나 삭제하지 않습니다.
봇 인증 정보는 Windows DPAPI를 사용하므로 같은 PC·Windows 계정에서 이전해야 유지됩니다.

## 다른 PC의 업데이트

- 새로 설치할 PC: 설치 EXE를 사용하세요. 각 PC의 기존 data는 해당 PC에서 선택합니다.
- v1.1.10 이하 또는 이전 로컬 빌드: Setup을 한 번 직접 실행해 전환하세요. 기존 EXE 다운로드 방식의 자동 업데이트는 이번 Setup 단일 파일 릴리스와 호환되지 않습니다.
- 이번 Setup으로 설치한 v1.1.11 이후: 다음 버전의 Setup을 사용자 캐시에 내려받아 GitHub의 SHA-256 검증값과 비교하고, 작업 완료 후 자동 종료·설치·재실행합니다.
- 릴리스 첨부 파일은 Setup EXE 하나입니다. 사용 안내는 이 릴리스 본문으로 제공합니다.
