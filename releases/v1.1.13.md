# 뉴스 모니터 v1.1.13

APT를 아파트 약어로 사용한 기사가 보안 사고로 수집·공유되는 문제를 수정했습니다.

- 기본 보안 분류에서 APT 단독 등장만으로 공격으로 판단하지 않고, 같은 문장의 가까운 공격·침해 또는 전산망 침투 문맥을 확인합니다.
- APT37, APT-37, APT 37 같은 공격 그룹 표기를 지원합니다. 예방·훈련·부인 문맥을 구분하며 별도로 확인된 개인정보 유출은 유지합니다.
- 기존 저장 기사 표시와 자동 공유에도 수정된 판정을 적용합니다. 원본 기사와 사용자 설정은 보존합니다.
- 일반 검색과 사용자 정의 분류의 문구 검색 방식은 유지합니다.

## 검증

실제 그린홈 으뜸아파트 오탐과 정상 APT 공격·입주민 개인정보 유출, Google/Bing 수집, 기존 기사 표시 및 공유 대기열 회귀 테스트를 추가했습니다. 로컬 전체 테스트는 환경 문제 재검증을 포함해 303개 통과, 데스크톱 IME 환경 테스트 1개 생략입니다. 저장 기사 1,679건을 대조하여 문제 기사 1건만 제외로 바뀌고 나머지 판정은 유지됨을 확인했습니다. 제목·RSS 설명에 나타난 근거를 사용하는 규칙 기반 판정입니다.

## 설치

기존 프로그램을 종료하고 릴리스에 첨부된 `NewsMonitor-Setup-1.1.13.exe`를 실행하세요. 기존 설정과 기사 데이터는 유지됩니다.
