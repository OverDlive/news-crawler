# 뉴스 모니터 v1.1.5

배포일: 2026-10-19 (한국 시간)

현재까지 개발한 기능을 1~25번으로 정리한 정식 Windows 업데이트입니다. v1.1.4 이후 변경 사항은 19~25번입니다. 기존의 기관별 여러 기사 묶음 공유는 기관별 대표 기사 한 건을 보내는 방식으로 변경했습니다.

1. **키워드 검색과 뉴스 수집**: 일반 키워드, AND/OR/NOT·괄호·제외어·확인 범위를 지원합니다. Google 뉴스 RSS 연결 실패 시 Bing으로 대체하며 자동·수동 수집과 재시도를 제공합니다.
2. **정부·공공기관 모니터링**: 정부 기관 60개와 지정 공공기관 342개의 이름·약칭을 제공합니다. 누락된 기본 기관만 최초 등록하고 기존 수정·중지 상태를 유지합니다.
3. **금융권 모니터링**: 은행·저축은행·카드사·캐피탈·핀테크와 금융당국을 지원합니다. 금융권 일괄 등록, 전체 필터와 금융정보 유출·조사·피해 대응 검색 조건을 제공합니다.
4. **보안 사고 관련성 필터**: 제목·RSS 설명에서 사이버 침해와 개인정보·데이터 유출 근거를 확인해 일반 문건 유출·홍보 등의 오탐을 줄입니다. 실제 침해에 따른 조사·과징금 기사는 유지하며 근거가 부족한 기사는 누락될 수 있습니다.
5. **본문 기반 중복 비교**: 제목·RSS 중복 판정에 더해 본문 TF-IDF·코사인 유사도를 비교합니다. 기관·피해 규모·발생 여부 등의 차이를 확인하며 본문이 없거나 짧으면 기존 방식으로 판정합니다.
6. **묶인 기사 확인**: 대표 카드에 묶인 기사 수를 표시하고 미리보기의 `함께 묶인 기사`에서 언론사별 제목·발행 시각과 각 원문을 확인할 수 있습니다.
7. **기사 요약과 저장**: 원문 핵심 문장을 발췌하고 본문 확인이 어려우면 RSS 설명으로 대체합니다. 설정·기사·요약을 저장해 재실행 후에도 유지합니다.
8. **카카오·텔레그램 공유**: 카카오 사용자별 수신 ON/OFF·토큰 자동 갱신과 텔레그램 단체방·채널 공유를 제공합니다. 전송 결과를 확인할 수 있으며 토큰은 Windows DPAPI로 보호합니다.
9. **설정 편집**: 기관·분류·개별 검색어 ON/OFF, 사용자 정의 분류, 텍스트 가져오기와 검색 조건 미리보기를 지원합니다. 분류별 검색어는 최대 200개이며 작은 창에서도 스크롤로 편집할 수 있습니다.
10. **모니터링 화면**: 라이트·다크·시스템 테마, 전체 화면, 자동 페이지 전환, NEW 강조와 키보드 이동을 제공합니다. 새 결과는 페이지 전환 또는 사용자가 적용할 때 반영합니다.
11. **화면 응답성**: 수집 결과를 나누어 처리하고 알림 저장·본문 비교를 백그라운드에서 수행해 결과가 몰릴 때 화면 멈춤을 줄입니다.
12. **EXE와 자동 업데이트**: Python 설치 없이 실행합니다. 설정에서 최신 버전을 확인하고 SHA-256 검증을 거친 새 EXE를 다음 실행 때 적용하며 이전 EXE를 백업합니다.
13. **수신 대상별 공유 중복 방지**: 카카오 수신자·텔레그램 방별 전송 이력과 비교합니다. URL이 다른 유사 기사, 묶음 대표 변경과 추적 매개변수 차이로 인한 재공유를 줄입니다.
14. **재시작·발송 직전 중복 검사**: 공유 이력을 유지하고 기존 대기열을 발송 직전에 다시 검사합니다. 제외된 기사는 전송 내역에서 확인할 수 있으며 결과 불명 기사는 자동 재전송하지 않습니다.
15. **텔레그램 무료 발송 유지**: 최소 4초 발송 간격과 요청 제한 응답에 따른 대기를 유지하고 유료 발송을 차단합니다.
16. **중요 뉴스 선별**: 제목에 근거가 있는 보안 사고·피해, 확정된 제재·법령 조치, 서비스·기반시설 장애를 우선합니다. 중요도 60점 이상을 공유 대상으로 선정합니다.
17. **본문 중심 중복 강화**: 공통 본문 비중이 큰 발췌 기사도 비교하고 광고·관련기사·기자 정보를 정리합니다. 피해 규모의 실제 변경은 구분하며 본문 묶음이 완성되면 공유 대기열도 재검사합니다.
18. **공유 대기열 초기화**: 카카오 사용자 또는 텔레그램 대상 방의 대기·중요도 제외·실패 기사를 초기화합니다. 초기화 전 기사의 재등록을 막고 설정·수집 기사·성공·결과 불명 이력은 유지합니다. 이미 전송 중인 메시지는 취소하지 않습니다.
19. **기관별 대표 기사 한 건 공유**: 전송 시점의 같은 기관 대기 기사 중 중요도가 가장 높은 기사 한 건을 보냅니다. 동점이면 발행 시각이 최신인 기사를 선택하며 기관이 불명확하거나 여러 기관이 주제인 기사는 개별 공유합니다. 이후 새로 수집된 중요 뉴스는 다음 전송에서 다시 선정합니다.
20. **이미지 미리보기**: 카카오는 원문 대표 이미지가 있으면 클릭 가능한 피드 카드, 없거나 조회에 실패하면 텍스트 링크를 보냅니다. 텔레그램은 대표 기사 URL의 큰 이미지 링크 미리보기를 요청합니다. 실제 이미지 표시는 기사 사이트·플랫폼 접근 가능 여부에 따르며 카카오의 기사 도메인 허용 설정이 필요합니다.
21. **원문 주소와 이미지 조회 개선**: Google 뉴스 중계 주소의 연결 정보를 사용해 언론사 원문을 확인하고 대표 이미지를 읽습니다. 확인할 수 없으면 검증된 검색 결과와 기존 링크로 대체하며 일시적인 이미지 조회 실패는 캐시에 고정하지 않습니다.
22. **대표 기사 전송 이력 구분**: 실제 발송한 대표 기사만 성공으로 기록하고 나머지 후보는 공유 제외로 기록해 다음에 다시 보내지 않습니다. 실패·요청 제한 시 후보를 유지하며 결과 불명은 자동 재전송하지 않습니다. 카카오 내역에는 실제 요청한 이미지 카드·텍스트 링크 형식을 표시합니다.
23. **수집 지연과 작업 수 제한**: 전체 수집 제한 시간은 검색 규모에 맞춰 늘리되 개별 요청 대기는 기본 설정에서 최대 80초로 제한합니다. 종료되지 않은 통신 작업을 포함해 서버별 작업을 최대 4개로 제한하고 늦게 끝난 결과는 반영하지 않습니다.
24. **절전 복귀·설정 변경 후 수집 개선**: 절전 복귀 시 이전 수집 종료를 기다리지 않고 새로 확인합니다. 설정 변경이나 복귀 이전의 늦은 완료 이벤트가 새 수집 상태와 다음 확인 시각을 바꾸지 않도록 합니다.
25. **장시간 실행 메모리 관리**: 본문 정규화·문자 조각 캐시를 각각 최근 128개로 제한하고 기사 쌍 비교에는 SQLite 캐시를 사용해 메모리 사용을 줄입니다.

## 다운로드 및 적용

- `NewsMonitor.exe`: Windows 실행 파일.
- `NewsMonitor.exe.sha256`: SHA-256 검증 파일.
- `RELEASE_NOTES.md`: 이 번호별 누적 개발 내용과 업데이트 안내.
- 기존 사용자는 설정 → `프로그램 / 업데이트` → `업데이트 확인` 후 다운로드가 끝나면 프로그램을 완전히 종료하고 다시 실행하세요.
- EXE 옆 `data/`를 유지하면 기존 설정·수집 기사·공유 이력을 이어서 사용합니다. 암호화된 토큰은 기존 Windows 계정과 PC에서 사용하세요.

프로그램 실행 중에만 수집·공유가 동작합니다. 이미지 확인 실패 시에도 기존 링크 공유로 대체하며 자동 요약·중복 판정·중요도 선별에는 누락이나 오탐이 있을 수 있습니다.
