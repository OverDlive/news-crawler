# 뉴스 모니터 v1.1.12

2026-11-04 로컬 최적화 빌드입니다. 기사 분석의 CPU·메모리 비용과 화면 작업 중 대기 시간을 줄였습니다.

1. **본문 비교 경량화**: 기사 쌍마다 TF-IDF 분석기를 생성하던 방식을 두 문서 전용 계산으로 교체했습니다. 문자 3~5그램, sublinear TF, smoothed IDF, L2 코사인과 기존 발췌 기사·사실 충돌 규칙을 유지합니다. NumPy·SciPy·scikit-learn을 앱과 EXE에서 제거했습니다.
2. **계산 재사용과 메모리 상한**: 본문별 특징을 재사용하며 최대 64개 본문·120,000개 특징 항목으로 캐시를 제한합니다. 큰 본문은 한 번 계산하되 캐시에 보관하지 않습니다. 비교 회차당 본문 해시는 기사마다 한 번 계산합니다. 제목의 반복 정규화 결과도 제한된 캐시에 재사용합니다.
3. **화면 응답성**: 실제 앱의 최초 기사 조회와 요약 대상 조회를 작업 스레드로 이동했습니다. 대량 본문 비교 결과도 작업 스레드에서 128건씩 저장합니다. 요약할 기사가 없을 때는 최소 5초 간격으로 조회하고 불필요한 전체 목록 갱신을 생략합니다.
4. **긴 목록과 데이터베이스**: 검색어 목록은 화면에 보이는 행과 여유 행만 그립니다. 스크롤·선택·키보드 이동을 유지하며 전체 목록 크기에 비례하는 그리기를 줄였습니다. 키워드 조회와 오래된 기사의 비교 결과 삭제에 필요한 SQLite 인덱스를 추가했습니다.

수집 범위, 요청 간격, 공유 보류 시간, 알림 대상과 중복 판정 임계값(0.82)은 유지합니다. 기존 캐시를 사용할 수 있고 원본 기사·설정을 삭제하지 않습니다. 부동소수점 연산 순서에 따른 매우 작은 점수 차이는 있을 수 있습니다.

## 측정 및 확인

동일 PC·Python 3.12.10, 합성 본문 32개/496쌍의 오프라인 비교에서 기존 방식 2.42초(라이브러리 로딩 후), 새 방식 0.17초를 기록했습니다. 최초 라이브러리 로딩을 포함한 기존 방식은 5.24초였습니다. 표본의 최대 점수 차이는 1.14×10⁻⁷ 미만이고 496개 중복 판정은 모두 같았습니다. 이 수치는 본문 비교 실험이며 앱 전체나 다른 PC에서 같은 배율을 보장하지 않습니다.

로컬 EXE는 약 76.5MB에서 14.1MB로 약 82% 줄었습니다. 설치 파일은 약 71.3MB에서 15.9MB로 약 78% 줄었습니다. 빌드 시각·Python 환경에 따라 파일 크기는 달라질 수 있습니다.

전체 296개 테스트를 통과했습니다. 실제 EXE 실행, 본문 비교, 백그라운드 조회, 통신 작업자의 시간 제한·복구, 업데이트 파일 교체·백업, 설치 업데이트 후 자동 재시작도 검증했습니다. 본문 계산은 외부 수치 연산 라이브러리가 없는 환경에서도 실행되며, 3,000개 검색어 목록의 그리기 항목 수가 화면 높이에 따라 제한되는 것을 확인했습니다. 렉이 보고된 다른 PC에서의 현장 측정은 아직 수행하지 않았습니다.

재현: `python scripts/benchmark_performance.py`. 이전 `news_similarity.py`와 scikit-learn을 별도로 준비하면 `--reference-file 경로`로 점수와 시간을 비교할 수 있습니다. 테스트와 측정은 임시·합성 데이터로 수행합니다.

## 적용

뉴스 모니터를 종료한 뒤 `dist/NewsMonitor-Setup-1.1.12.exe`를 실행하세요. 기존 설치형 앱은 같은 설치 경로를 사용하며 사용자 데이터는 유지합니다. 포터블 방식에서 전환할 때는 해당 PC의 기존 `data` 폴더를 선택하세요. 창 제목에서 **v1.1.12**를 확인할 수 있습니다. 이 변경은 로컬 빌드이며 GitHub 게시·다른 PC 자동 배포는 수행하지 않았습니다.

## 기술 근거

- [Python Tkinter 스레딩 모델](https://docs.python.org/3/library/tkinter.html#threading-model): 이벤트 처리에서 긴 계산·입출력을 분리해야 화면 입력이 막히지 않습니다.
- [scikit-learn TF-IDF 공식](https://scikit-learn.org/stable/modules/generated/sklearn.feature_extraction.text.TfidfTransformer.html): 두 문서에서 공통 특징의 IDF는 1, 한 문서만의 특징은 1+log(3/2)입니다. 이 관계로 동일 공식을 직접 계산합니다.
- [PyInstaller 실행 방식](https://pyinstaller.org/en/stable/operating-mode.html#how-the-one-file-program-works): 단일 EXE는 실행 전에 구성 파일을 임시 폴더에 풉니다. 불필요한 수치 연산 라이브러리 제거로 압축 해제할 파일도 줄입니다.
