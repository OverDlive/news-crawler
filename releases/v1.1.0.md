# 뉴스 모니터 v1.1.0

배포일: 2026-10-09 (한국 시간)

현재까지 개발된 기능을 통합한 정식 Windows 업데이트입니다. v1.0.2 이후의 주요 추가 사항은 2~6번, 9번, 11번입니다.

1. **키워드 검색과 뉴스 수집**: 일반 키워드, AND/OR/NOT·괄호·제외어·확인 범위를 지원합니다. Google 뉴스 RSS 연결 실패 시 Bing으로 대체하며, 자동·수동 수집과 오류 재시도를 제공합니다.
2. **정부·공공기관 모니터링 확대**: 정부 기관 60개와 지정 공공기관 342개, 총 402개의 이름·약칭을 제공합니다. 누락된 기본 기관만 최초 등록하고 기존 수정·중지 상태를 유지합니다.
3. **금융권 모니터링**: 은행·저축은행·카드사·캐피탈·핀테크와 금융당국을 지원합니다. 금융권 일괄 등록, 금융권 전체 필터, 신용정보·카드정보 유출 및 조사·피해 대응 검색 조건을 제공합니다.
4. **보안 사고 관련성 필터**: 실제 사이버 침해·개인정보 및 데이터 유출/노출 근거를 확인합니다. 근거 없는 일반 문건 유출, 채용·교육·홍보와 소송 중심 기사 등의 오탐을 줄이고, 실제 침해에 따른 조사·과징금 기사는 유지합니다. 제목·RSS 설명에 근거가 부족한 기사는 누락될 수 있습니다.
5. **본문 기반 중복 비교**: 제목·RSS 기반 중복 통합에 더해 scikit-learn의 TF-IDF·코사인 유사도로 수집한 본문을 비교합니다. 기관·수치·날짜·부정 표현 차이는 분리하고, 본문이 없거나 짧으면 기존 방식으로 판정합니다.
6. **묶인 기사 확인 화면**: 대표 카드에 묶인 기사 수를 표시합니다. 미리보기의 `함께 묶인 기사`에서 언론사별 제목·발행 시각을 확인하고 각 원문을 열 수 있습니다.
7. **기사 요약과 저장**: 본문에서 핵심 문장을 발췌하고 본문 확인이 어려우면 RSS 설명으로 대체합니다. 설정·기사·요약을 SQLite에 저장하여 재실행 후에도 유지합니다.
8. **카카오·텔레그램 공유**: 카카오 사용자별 알림·수신 ON/OFF·토큰 자동 갱신과 텔레그램 단체방·채널 공유를 제공합니다. 중복 발송 방지와 전송 결과 확인을 지원하고 Windows DPAPI로 토큰을 보호합니다.
9. **설정 편집 개선**: 기관·분류·개별 검색어 ON/OFF, 사용자 정의 분류, 텍스트 파일 가져오기와 검색 조건 미리보기를 지원합니다. 분류별 검색어는 최대 200개이며 작은 창에서도 스크롤로 편집할 수 있습니다.
10. **모니터링 화면**: 라이트·다크·시스템 테마, 전체 화면, 자동 페이지 전환, NEW 강조, 키보드 이동과 기사 미리보기를 제공합니다. 읽는 중 새 결과가 카드 위치를 바꾸지 않도록 처리합니다.
11. **응답성과 실행 개선**: 수집 결과 폭주 시 UI 작업을 나누고 알림 저장·본문 비교를 백그라운드에서 처리합니다. Windows EXE와 창에 프로그램 아이콘을 적용하고 패키징된 본문 비교 기능도 검증합니다.
12. **EXE 배포와 자동 업데이트**: Python 설치 없이 실행합니다. 설정의 `프로그램 / 업데이트`에서 현재·최신 버전과 마지막 확인 시각을 보고 즉시 확인할 수 있습니다. 새 EXE는 SHA-256 검증 후 다음 실행 때 적용하며 이전 EXE를 백업합니다.

## 다운로드 및 적용

- `NewsMonitor.exe`: Windows 실행 파일. 쓰기 가능한 개인 폴더에서 사용하세요.
- `NewsMonitor.exe.sha256`: 실행 파일의 SHA-256 검증 정보.
- `RELEASE_NOTES.md`: 이 번호별 개발 내용과 업데이트 안내.
- 기존 사용자는 설정 → `프로그램 / 업데이트` → `업데이트 확인` 후 다운로드가 완료되면 프로그램을 종료하고 다시 실행하세요.
- EXE 옆의 `data/`를 유지하면 기존 설정·기사·알림 정보를 이어서 사용합니다. 암호화된 토큰은 기존 Windows 계정과 PC에서 사용하세요.

최초 업데이트에서 기본 기관·금융권 항목이 추가될 수 있으므로 필요한 기관의 사용 상태를 설정에서 확인하세요. 프로그램 실행 중에만 뉴스 수집과 알림 발송이 동작합니다.
