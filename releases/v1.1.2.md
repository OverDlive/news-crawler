# 뉴스 모니터 v1.1.2

배포일: 2026-10-15 (한국 시간)

1. **같은 사건 묶음 강화**: 금융기관·정부·공공기관의 정식 명칭과 약칭을 통일하고 유출/노출 등 사건 표현을 비교합니다. 같은 피해 수치나 대응 지연 기간을 근거로 제목이 다른 기사도 통합합니다. 기관·피해 규모·발생 여부가 다른 기사는 분리합니다.
2. **본문 묶음의 공유 이력 반영**: 이미 공유한 기사도 뒤늦게 확인된 묶음 구성 정보를 이력에 반영하여 다른 제목·URL로 같은 사건을 재공유하는 일을 줄입니다. 전송 결과와 재시작 후 이력은 유지합니다.
3. **중요 뉴스 자동 선별**: 제목에 근거가 있는 보안 사고·피해, 확정된 제재·법령 조치, 서비스·기반시설 장애를 공유합니다. 행사·홍보·채용과 해설·전망, 중요 사건 근거가 부족한 기사는 공유 내역에 `중요도 제외`와 이유를 표시합니다. 수집 기사와 화면 조회는 유지합니다.
4. **우선순위와 대기열 재검사**: 카카오·텔레그램 모두 중요도 높은 기사를 먼저 보내며, 기존 대기열도 전송 직전에 재검사합니다. 중요도 제외 후 기사·묶음 정보가 보강되면 재평가합니다. 단독 보도도 중요 사건 근거가 있으면 공유합니다.

중요도는 규칙 기반이며 모든 중요 뉴스를 판별하지는 못합니다. 유료 발송 차단과 기존 발송 간격은 유지합니다.

## 다운로드 및 적용

- `NewsMonitor.exe`: Windows 실행 파일.
- `NewsMonitor.exe.sha256`: 실행 파일의 SHA-256 검증 정보.
- `RELEASE_NOTES.md`: 업데이트 안내.
- 기존 사용자는 설정 → `프로그램 / 업데이트` → `업데이트 확인` 후 다운로드가 완료되면 프로그램을 종료하고 다시 실행하세요.
- EXE 옆의 `data/`를 유지하면 기존 설정·기사·공유 이력을 이어서 사용합니다.

검증: 회귀 테스트 187개(일반 135개·GUI 52개), 패키징된 GUI 실행 및 실제 업데이트 교체·백업·재시작 테스트 통과.
