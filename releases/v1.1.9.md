# 뉴스 모니터 v1.1.9

배포일: 2026-10-27 (한국 시간)

같은 제목이나 내용이 비슷한 뉴스가 반복 공유되는 경우를 줄이는 정식 Windows 업데이트입니다. 기존 1~36번 기능은 [v1.1.8 누적 안내](https://github.com/OverDlive/news-crawler/blob/v1.1.8/releases/v1.1.8.md)를 참고하세요.

37. **제목 표기 차이 처리**: 공백·따옴표·HTML 문자·국감 표시·확인된 언론사 접미사를 정리합니다. `2.4만명`과 `2만4천명`을 같은 수치로 취급하며 긴 핵심 제목이 동일한 기사도 통합합니다. 피해 규모나 명시된 연도 변경, 행사 취소 등은 분리합니다.
38. **재수집 기사 재공유 차단**: 정규화한 제목이 동일하고 12자 이상이면 발행 시각 차이가 7일 이내인 기사까지 공유 이력과 비교합니다. 서로 다른 RSS 주소가 같은 원문으로 연결되는 경우도 중복 처리합니다. 일반 제목·본문 유사도 비교는 48시간 범위를 유지합니다.
39. **본문 분석 대기**: 수집·비교가 끝나지 않은 새 기사는 최초 대기열 등록 후 최대 2분 기다린 뒤 공유합니다. 분석이 먼저 끝나면 바로 재검사하고, 재시작·반복 수집으로 대기 시간이 늘어나지 않습니다. 본문을 가져오지 못해도 제한 시간 후 제목 검사로 공유를 계속합니다.
40. **발송 직전 본문 재확인**: 카카오·텔레그램 모두 저장된 본문 비교 결과를 발송 직전에 읽습니다. 화면의 대표 기사 묶음 갱신보다 먼저 발송되는 경우와 현재 조회 기간 밖에 있는 기존 공유 기사도 확인합니다. 본문이 바뀐 캐시는 무시하고 명확한 사실 충돌이 있으면 별개 기사로 취급합니다.

## 다른 PC에 적용

### 자동 업데이트

자동 업데이트를 지원하는 기존 정식 EXE는 시작 5초 후 또는 실행 중 6시간마다 최신 정식 릴리스를 확인합니다. 바로 적용하려면 `키워드 / 설정` → `프로그램 / 업데이트` → `업데이트 확인`을 누르세요.

v1.1.9 실행 파일 다운로드와 SHA-256 검증이 완료되면 프로그램을 종료한 뒤 다시 실행합니다. 다음 실행 시 파일을 교체하고 자동으로 재시작하며 기존 설정·기사·공유 이력을 이어 사용합니다. `--no-update` 옵션을 사용한 실행에서는 업데이트를 확인하지 않습니다.

### 수동 교체

1. 뉴스 모니터를 종료합니다.
2. 기존 실행 파일을 백업하고 같은 폴더의 `NewsMonitor.exe`를 수정본으로 교체합니다.
3. 기존 실행 파일 옆의 `data` 폴더는 그대로 유지합니다. 기사·설정·공유 이력을 이어 사용해야 기존에 보낸 뉴스의 재공유를 막을 수 있습니다.
4. 실행 후 `프로그램 / 업데이트`에서 버전 `1.1.9`를 확인합니다.

GitHub 릴리스에는 `NewsMonitor.exe`, `NewsMonitor.exe.sha256`, `RELEASE_NOTES.md`를 제공합니다. 사용자 데이터나 인증 정보는 배포 파일에 포함하지 않습니다.

제목을 크게 바꿨고 본문을 확보하지 못한 경우까지 완전한 중복 제거를 보장하지는 않습니다. 이미 전송된 메시지는 삭제하지 않습니다.
